01 / Product vision

A major DEWIFY pillar.

DTA is positioned alongside the template business, not underneath it. The goal is a universal market-analysis experience that can start simple for beginners while leaving room for deeper tools as the product grows.

Universal chart workflow

Start with the chart the user already has open. The experience is centered on the visible chart and its context.

Reasoned output

Surface the analytical basis behind a result instead of presenting a mysterious one-word signal.

Beginner-first clarity

Make the interface understandable at a glance, with progressive depth for more experienced users.

02 / Workflow

Open. Detect. Analyze. Understand.

The product flow can grow around a simple loop: identify the visible chart, inspect its visual structure, build a baseline, evaluate patterns and present the result with context.

01 / DETECT

See the chart

Recognize the chart area, ticker or asset label and visible timeframe where available.

02 / STRUCTURE

Read the setup

Look at candles, direction, support/resistance and the visible price structure.

03 / REASON

Build the analysis

Use baseline and pattern context to explain what the chart is showing.

04 / PRESENT

Show the result

Return concise tags, reasons and optional hover details inside the overlay experience.

03 / Feature direction

The interface is built for depth.

Floating overlay

A compact desktop experience that can sit beside or over the chart without taking over the whole screen.

Manual asset input

Let the user provide a ticker or asset name when the visible chart does not make it obvious.

Chart / candle recognition

Designed as a visual-analysis pipeline rather than relying only on broker-specific integrations.

Baseline visualization

Show the analytical baseline directly on the visible chart so the reasoning is easier to inspect.

Explainable tags

Buy, sell or wait-style labels can carry concise reasons instead of acting as unexplained outputs.

Multiple-chart expansion

One-chart analysis can remain the focused core while multi-chart workflows become a future capability.

05 / FAQ

Questions, answered.

Is DTA a broker?

No. DTA is positioned as analysis software. It can be used around a visible chart rather than being the brokerage account itself.

Is DTA automated trading?

The current product direction is centered on market analysis and chart intelligence. Automated order execution is a separate capability that would require its own broker/API layer and validation.

Who is DTA for?

The intended audience starts with beginners, while the architecture leaves room for experienced users who want more analytical depth.
